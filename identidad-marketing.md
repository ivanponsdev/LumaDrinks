IDENTIDAD VISUAL DE LUMA
Concepto visual
La identidad visual de Luma se basa en un enfoque minimalista, limpio y
calmado, alineado con los valores de bienestar, claridad mental y equilibrio.
● El naming Luma: proviene de la palabra “luz” (luminosidad), y se asocia
conceptualmente con la claridad mental, la calma y la sensación de
iluminación interna. No se entiende como una luz intensa o estimulante, sino
como una luz suave y difusa, que acompaña y guía sin invadir.
Luma representa:
● claridad sin sobreestimulación
● calma mental
● equilibrio interno
● momentos de pausa y conexión
Desde el punto de vista emocional, la marca transmite la idea de reducir el ruido
mental y encontrar un estado más limpio y ordenado, donde el usuario puede
sentirse más enfocado, relajado o en equilibrio según sus necesidades.
El diseño visual refuerza este concepto mediante:

● uso de espacios en blanco
● tonos suaves y desaturados
● ausencia de elementos agresivos o recargados
Aplicación en web:
La interfaz debe sentirse como un espacio de calma, casi meditativo, donde el
usuario navega sin distracciones, con una experiencia fluida, clara y ligera.
Logotipo
El logotipo se construye a partir de una tipografía sans-serif de gran peso, con
formas redondeadas.
Características:
● Tipografía gruesa → aporta presencia
● Formas curvas → transmiten suavidad y calma
● Estética moderna → alineada con marcas wellness
Elemento distintivo: El símbolo derivado de la “m” funciona como icono de marca.
Aplicación en web:
● Usar el símbolo como favicon
● Usarlo como elemento visual en loading, botones o secciones
● Puede funcionar como patrón o recurso gráfico sutil
SISTEMA CROMÁTICO
La identidad se basa en una paleta de neutros cálidos + un color acento.
Colores principales
● Blanco roto → #F7F5F2
● Beige → #E8E1D9
● Marrón claro → #B7A89A
● Negro suave → #2B2B2B
Aplicación en web:
● #F7F5F2 → fondo principal (evita blanco puro → más premium)
● #E8E1D9 → bloques, tarjetas, secciones
● #2B2B2B → textos principales
● #B7A89A → textos secundarios / descripciones

Esto crea una web limpia, elegante y nada agresiva visualmente.
Color acento
● Verde desaturado → #7A8F7C
Aplicación en web:
● Botones (CTA)
● Hover states
● Elementos interactivos
● Detalles pequeños (líneas, iconos)
Importante: usarlo con moderación → así mantiene el efecto premium
Uso del color en el logotipo
Versiones recomendadas:
● Negro sobre fondo claro
● Blanco sobre fondo oscuro
● Beige / tonos neutros
● Versión puntual con acento

El logo no debe depender del color acento → la marca debe funcionar en neutro.
Tipografía
La tipografía debe seguir la misma lógica que el logo: limpia, moderna, sin ruido
tipografía principal (recomendada)
Puedes usar:
● Sans-serif moderna tipo:
○ Inter
○ Helvetica Neue
○ Neue Haas Grotesk
○ Satoshi (muy buena opción)

Uso:
● textos generales
● párrafos
● UI de la web

Tipografía secundaria (opcional)
Para dar un toque más editorial/lifestyle:
● Canela
● Playfair Display (muy sutil)
Uso:
● titulares
● frases de marca
Pero ojo: no abuses → la marca debe seguir siendo minimalista
Estilo visual
La marca sigue estos principios:
● Mucho espacio en blanco
● Composición limpia
● Pocos elementos por pantalla
● Colores suaves
● Ritmo visual lento
Aplicación en web:
● No saturar con textos
● Usar bloques grandes y aireados
● Priorizar scroll limpio
Tono de la marca
El tono es tan minimalista como lo visual.
Características:
● Calmado
● Cercano
● Simple
● Sin tecnicismos innecesarios
● Sin exageración

Ejemplos de tono (muy útil para web)
Hero (inicio web):

● “Encuentra tu equilibrio”
● “Menos ruido, más claridad”
● “Elige cómo quieres sentirte”
Botones:
● “Descubrir”
● “Empezar”
● “Encontrar mi bebida”
Mensajes:
● “Cada momento necesita algo distinto”
● “Escucha lo que tu mente necesita”
● “No es energía, es equilibrio”
Aplicaciones
La identidad está pensada para:
● Web (principal canal)
● Packaging
● Redes sociales
● Branding digital
En web:
La experiencia debe sentirse como:
● un espacio tranquilo
● casi como una app de bienestar
